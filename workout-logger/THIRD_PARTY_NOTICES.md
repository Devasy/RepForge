# Body diagram geometry

Muscle outlines are derived from MuscleMap by Melih Colpan (https://github.com/melihcolpan/MuscleMap), via openGym's body-paths.js at commit f049465c1e4732c84e7077286dc99a66fdd2ed23 (https://github.com/DuarteSantos8/openGym).
Only the MIT-licensed geometry is reused. The Flutter renderer and RepForge muscle mapping are implemented for RepForge.

## Free Exercise DB reference guides

Technique instructions and optional reference photos are sourced from
[yuhonas/free-exercise-db](https://github.com/yuhonas/free-exercise-db),
commit f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5. The repository describes the
dataset and imagery as public domain under the Unlicense (LICENSE.md).
Photos are downloaded only after the user requests a guide; this app does not
use or redistribute openGym's ExerciseDB/Gym Visual animations or its AGPL code.

The six reference variants are Barbell Bench Press - Medium Grip, Barbell Full
Squat, Barbell Deadlift, Standing Military Press, Barbell Curl, and Pushups.
