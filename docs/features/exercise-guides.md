# Exercise guides

Six exact built-in exercise variants have instructions and two curated reference photos each. Instructions are bundled with RepForge. Photos download only when a user taps **Download photo guide** on an exercise, or **Download all exercise guides** in Profile. The Profile action saves all 12 photos for offline viewing and can be retried after an interruption. Existing photos are skipped.

The app stores these fixed photos in its private cache. Users cannot attach or import media. Custom and unsupported exercises have no photo guide. Cached photos are not included in workout backups; users can download them again after reinstalling or restoring a backup.

Reference content: [Free Exercise DB](https://github.com/yuhonas/free-exercise-db) at commit `f00c92c7dcf1216a928a52c3706c7ce8e2f71ed5`, Unlicense. Guides are matched to exact variants to avoid showing a different movement under a generic exercise name.
